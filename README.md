A complete backend for an e-commerce application:

- 🔐 **Auth** — registration & login with **bcrypt** hashing and **JWT** stored in HTTP-only cookies
- 🛡️ **RBAC** — customer & merchant roles with protected routes via custom middleware
- 📦 **Products** — full CRUD, get by ID, search by name or description
- 🛒 **Cart & Orders** — add / update / remove / view cart, checkout converts cart → order, calculates totals, and clears the cart
- ✅ **Validation** — all request bodies validated with **Zod**
- 🗂️ **Structure** — routes, middleware, and a centralized data-access helper (JSON storage)
