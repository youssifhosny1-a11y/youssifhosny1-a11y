## Featured Project

### 🛒 [E-Commerce Backend API](https://github.com/youssifhosny1-a11y/ecommerce)

`Node.js` `Express.js` `JWT` `bcrypt` `Zod`

A complete backend for an e-commerce app.

- **Auth:** register / login with bcrypt hashing and JWT in HTTP-only cookies
- **RBAC:** customer and merchant roles with protected routes via custom middleware
- **Products:** full CRUD, get by ID, search by name or description
- **Cart & Orders:** add, update, remove, view; checkout turns the cart into an order, calculates totals and clears the cart
- **Validation:** every request body validated with Zod
- **Structure:** routes, middleware and a centralized data-access helper
